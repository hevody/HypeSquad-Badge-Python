# HypeSquad Badge Python ⚔️

Discord removed the HypeSquad badges. Or did they?
<br><br>
Discord still respond to API requests regarding Hypesquad Houses so it's not completely removed yet. That is why you might've seen other users who have HypeSquad badges even though it was reportedly discontinued. Therefore, I made this Python script as a new **method** to help you acquire the HypeSquad badge if you still haven't

# Prerequisites 🛠️
- `Python` installed
- `Windows`, `MAC OS`, or `Linux` Operating System
- A browser
- Internet connection
- Discord account

# Installation 📥

```
git clone https://github.com/hevody/HypeSquad-Badge-Python.git
```

# 💡 How to get the Discord Token? 
1. Head over to **https://discord.com/app**
   Log In if prompted 

2. Press **`Ctrl + Shift + I`** to open up your browser's Developer Options

3. Head over to **`Application`** in the Developer Options header
   <br>
   If you cannot see it click on **`>>>`** That will show you the **`Application`**

   <img width="424" height="auto" alt="Image" src="https://github.com/user-attachments/assets/83b4bf78-9b71-4393-b793-69d0d7c30b53" />

4. Click **`Local storage`** > **`https://discord.com`** > **`Filter`**

   <img width="424" height="288" alt="Image" src="https://github.com/user-attachments/assets/1c47bfb7-6117-4744-abe0-4ace727e1136" />

6. Type in **`token`**
   <br>
   You will see key and value pairs

7. Double-click the value of **`token`**, right-click, then **`Copy`**
